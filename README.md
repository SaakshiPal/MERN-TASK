# 🚀 Full Stack MERN User Management System

## 📌 Project Overview

This is a Full Stack MERN (MongoDB, Express, React, Node.js) User Management System developed as part of the Full Stack Intern Assessment Task.

The application allows users to:

- Add new users
- Edit user details
- Delete users
- View user details
- Search users
- Export user data to CSV
- Pagination support

The project is fully functional with both frontend and backend.

---

# 🛠 Tech Stack

## 🔹 Frontend
- React.js
- React Router DOM
- Axios

## 🔹 Backend
- Node.js
- Express.js
- MongoDB (Mongoose)
- json2csv

## 🔹 Database
- MongoDB Atlas

## 🔹 Deployment
- Frontend: Netlify
- Backend: Render
